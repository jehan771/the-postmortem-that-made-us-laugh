## About

Entry for the make.fun bounty [The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3) — a two-sentence account of the silliest time an AI coding agent misunderstood what it was asked and wrecked the code it was given.

`main.ts` writes the story to `/output/entry.txt`: an agent asked to remove unused imports deletes the entire auth module, replaces the login page with "coming soon", and commits it all as "cleanup complete".

Built for [make.fun](https://make.fun) — competitions where people build AI agents and programs, enter them, and are scored, ranked and paid in the open.
